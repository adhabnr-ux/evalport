OpenEval

The Open LLM Evaluation Standard

A portable format for evaluation test cases, graders, suites, and results.
Share eval datasets across DeepEval, Promptfoo, Ragas, Inspect AI, and more.

# Create an eval suite openeval init my-eval-suite # Validate it openeval validate my-eval-suite.json # Convert from Promptfoo openeval convert promptfoo openeval config.json output.json # Python SDK from openeval.validate import validate_suite result = validate_suite(my_suite) print(result.valid) # True

Why OpenEval?

11 Grader Types

exact_match, contains, regex, semantic_similarity, llm_judge, json_schema, json_path, code, human, and more.

Framework Converters

Import from Promptfoo, DeepEval, Inspect AI, and OpenAI Evals. Export back. No lock-in.

JSON + YAML + JSONL

Human-readable formats. Stream large suites with JSONL. Use YAML for config files.

Two SDKs

TypeScript and Python SDKs with validation, conversion, and summary computation.

Provider-Agnostic

Works with any LLM provider. No vendor lock-in. Self-hosted models supported.

Apache 2.0

Open source, no strings attached. Governed by the community.

OpenEval is an open specification under Apache 2.0.
